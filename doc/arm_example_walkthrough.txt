Program memory is set up like this:

Address 0: 8'h03  -> LDA 3
Address 1: 8'h16  -> ADDA 6
Address 3: 8'd4
Address 6: 8'd5

This matches the waveform generated by test/main_test.v and the hierarchy inside main_test.vcd.

Waveform reference

The most important signals to watch in main_test.vcd are DUT.CPU.CU.PC_out, DUT.CPU.CU.PC_inc, DUT.CPU.CU.MAR_in, DUT.CPU.CU.MEM_rd, DUT.CPU.CU.IR_in, DUT.CPU.CU.IR_out, DUT.CPU.CU.B_in, DUT.CPU.CU.A_in, DUT.CPU.CU.ALU_out, DUT.CPU.CU.ALU_op, bus, DUT.CPU.PC_val, DUT.CPU.MAR, DUT.CPU.IR, DUT.CPU.A_wire, and DUT.CPU.B_wire.

When a control signal changes from LOW to HIGH, the corresponding module places data on the bus or loads data from the bus on the next rising clock edge.

| State | Control signals HIGH | What happens |
|------|----------------------|--------------|
| T0 | DUT.CPU.CU.PC_out, DUT.CPU.CU.MAR_in | PC_val drives the bus, and DUT.CPU.MAR loads the current instruction address |
| T1 | DUT.CPU.CU.PC_inc, DUT.CPU.CU.MEM_rd, DUT.CPU.CU.IR_in | Memory places the instruction byte on the bus, DUT.CPU.IR loads it, and DUT.CPU.PC_val advances to the next address |
| T2 | depends on opcode | The control unit selects the execute sequence for the current instruction |
| LDA_st1 | DUT.CPU.CU.IR_out, DUT.CPU.CU.MAR_in | The operand field from IR drives the bus and DUT.CPU.MAR loads the data address |
| LDA_st2 | DUT.CPU.CU.MEM_rd, DUT.CPU.CU.A_in | Memory outputs the data value and register A loads it |
| ADDA_st1 | DUT.CPU.CU.IR_out, DUT.CPU.CU.MAR_in | The operand field from IR drives the bus and DUT.CPU.MAR loads the data address |
| ADDA_st2 | DUT.CPU.CU.MEM_rd, DUT.CPU.CU.B_in | Memory outputs the data value and register B loads it |
| ADDA_st3 | DUT.CPU.CU.ALU_out, DUT.CPU.CU.A_in, DUT.CPU.CU.ALU_op = A_add_B | The ALU adds A and B, then the result is written back into A |

Observed main_test waveform

The waveform in main_test.vcd shows these key transitions:

1. Reset is asserted first, then released.
2. In state 00, PC_out and MAR_in are active, so the bus carries 03 and DUT.CPU.MAR captures address 0.
3. In state 01, PC_inc, MEM_rd, and IR_in are active, so the instruction 03 is loaded into IR_reg and the PC advances to 1.
4. In state 02, the control unit decodes the opcode and the bus goes high impedance.
5. In state 03, IR_out and MAR_in are active, so the operand 3 is placed on the bus and DUT.CPU.MAR loads address 3.
6. In state 04, MEM_rd and A_in are active, so memory outputs 04 and A_data becomes 04.
7. The next fetch cycle begins from PC value 1, and the bus carries 16 for the ADD instruction.
8. In state 05, IR_out and MAR_in are active again, so the operand 6 is placed on the bus and DUT.CPU.MAR loads address 6.
9. In state 06, MEM_rd and B_in are active, so memory outputs 05 and B_data becomes 05.
10. In state 07, ALU_out, A_in, and ALU_op = A_add_B are active, so the ALU produces 09 and A_data becomes 09.
11. The following fetch cycle shows PC value 2 on the bus, confirming the PC advanced correctly through both instructions.

1. LDA 3

LDA 3 loads register A with the value stored at memory address 3, which is 4.

T0 - Address State

The control unit starts in T0. At this step, PC_out and MAR_in are HIGH, while PC_inc, MEM_rd, IR_in, IR_out, and A_in stay LOW. The Program Counter value 0 is placed on the bus by the pc module, and the MAR captures that value on the rising clock edge.

T1 - Fetch State

The control unit moves to T1. Here, PC_inc, MEM_rd, and IR_in are HIGH at the same time. The memory reads the instruction byte at address 0, which is 8'h03, and drives it onto the bus. At the rising clock edge, IR_in stores that byte into the Instruction Register, and PC_inc advances the Program Counter from 0 to 1.

T2 - Decode State

The control unit moves to T2. Because the opcode in IR[7:4] is 0000, the control unit branches to LDA_st1.

LDA_st1

IR_out and MAR_in go HIGH. The lower four bits of the instruction register are 3, so the zero-extended operand value 8'h03 is placed on the bus and MAR captures the address 3.

LDA_st2

MEM_rd and A_in go HIGH. Memory reads the byte at address 3, which is 4, and places it on the bus. On the rising clock edge, register A loads that value.

After LDA_st2, register A holds 4.

1.2 ADD 6

The ADD 6 instruction adds the value stored at memory address 6, which is 5, to the current value in register A, which is 4. The result is then stored back in register A.

T0 - Address State

The control unit returns to T0. PC_out and MAR_in are HIGH, while PC_inc, MEM_rd, IR_in, IR_out, and A_in stay LOW. The current PC value, which is now 1, is placed on the bus by the pc module and stored in the MAR. This prepares memory to be read from address 1.

T1 - Fetch State

The control unit moves to T1. PC_inc, MEM_rd, and IR_in all go HIGH at the same time. The memory reads the instruction at address 1, which is the ADD 6 opcode, and drives 8'h16 onto the bus. Because IR_in is HIGH, the IR loads this instruction byte on the rising clock edge. At the same time, PC_inc advances the PC from 1 to 2.

T2 - Decode State

The control unit moves to T2. The opcode in IR[7:4] is 0001, so the control unit branches to ADDA_st1.

ADDA_st1

IR_out and MAR_in go HIGH. The operand field from the IR is 6, so the bus carries 8'h06 and the MAR loads address 6.

ADDA_st2

MEM_rd and B_in go HIGH. The memory outputs the value 5 from address 6, and the B register loads that value on the rising clock edge.

ADDA_st3

ALU_out, A_in, and ALU_op = A_add_B are active. The ALU receives register A with value 4 and register B with value 5, then computes 4 + 5 = 9. Because A_in is HIGH, the result of 9 is stored back into register A on the rising clock edge.

After ADDA_st3 finishes, register A holds the value 9.

Result

The final result is:

A = 9

So our code performs the equivalent of:
LDR A, [3]
ADD A, [6]

using the SAP-1 instruction forms LDA 3 and ADDA 6.
